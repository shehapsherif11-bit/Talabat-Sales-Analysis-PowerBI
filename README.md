### 📌 Project Overview
This project transforms raw delivery data into actionable business insights for **Talabat**. The dashboard is designed to help stakeholders monitor key performance indicators (KPIs), analyze customer behavior, and identify growth opportunities across different cities.

The goal was to move beyond simple reporting to **Strategic Analysis**, focusing on Revenue Growth, Customer Retention, and Churn Prevention.

---

### 🚀 Key Features & Insights
* **📈 Sales Performance:** Tracking Total Revenue, Orders, and Average Order Value (AOV) with Year-over-Year (YoY) growth analysis.
* **👥 Customer Segmentation:** Deep dive into **Retention Rates**, **Churn Analysis**, and identifying New vs. Lost customers.
* **🌍 Geographical Analysis:** Performance breakdown by city to identify top-performing markets and areas needing improvement.
* **🎨 UI/UX Design:** A custom, user-friendly background designed in **Figma** to enhance user experience and navigation.

---

### 🛠️ Technical Stack (Skills Used)
* **Power BI:** Data visualization and interactive reporting.
* **Power Query (ETL):** Data cleaning, transformation, and creating a Star Schema data model.
* **DAX (Data Analysis Expressions):** Wrote complex measures for time-intelligence and customer metrics (e.g., `Churn Rate`, `Retention %`).
* **Data Modeling:** Built relationships between Fact and Dimension tables for accurate filtering.
